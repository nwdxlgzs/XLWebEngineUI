微质感（Layered）风格通过 半透明底衬（营造光晕/底座感）+ 实心主体（保证分量）+ 留白/线条细节（增加精致度）三层结构，完美平衡了“纯镂空太单薄、纯实心太死板”的问题。在 UI 中既适合作为选中态，也适合大尺寸展示。
