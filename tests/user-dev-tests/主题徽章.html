设 计 说 明

徽章采用五层微质感结构：最外层 opacity .09 的光斑营造发光氛围，底部椭圆光晕承托主体，实心主体保证分量，opacity .3~.5 的高光与点缀增加精致度。所有颜色来自 currentColor，在深底、浅底、渐变底上均保持层次，是弹窗主题选择器的理想形态。
