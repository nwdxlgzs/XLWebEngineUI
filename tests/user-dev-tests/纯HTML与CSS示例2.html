01 — Typography

排版：从首字到注音

原生 HTML 元素已经足够表达复杂的文字结构。

排版的本质，是让文字在被读到之前，先被看见。首字下沉（drop cap）通过 ::first-letter 伪元素实现，不需要额外包裹标签。 段落中的 高亮、CSS 缩写，以及 <code>、<kbd>、 <samp>、<var> 等语义元素， 都直接映射到浏览器默认样式或一层薄薄的修饰。

排版不是装饰，是让信息在页面里找到自己的呼吸。

04 — Interaction

所有切换都由锚点、复选框、details 与 popover 原生驱动。

:target 标签页

概览 实现 注意

概览

点击上方标签，URL 的片段标识（hash）会随之变化。 :target 伪类捕获当前被定位的面板， 对应的标签通过 :has(#tab-x:target) 高亮。

  • 面板默认全部隐藏；
  • 首个面板在没有 target 时显示；
  • 整页无需任何脚本。

实现

核心只有三条规则：

  • .tab-panel { display: none }
  • .tabs .tab-panel:target { display: block }
  • .tabs:not(:has(.tab-panel:target)) .tab-panel:first-child { display: block }

注意

若浏览器不支持 :has()，标签不会高亮， 但面板切换依旧工作；如果点击了页面其他锚点，标签页会回到第一个面板。

details / summary 折叠面板

为什么要用层叠层（@layer）？
层叠层把样式拆成若干有序分组，优先级不再由选择器长度决定。 本页使用 reset → tokens → base → layout → components → utilities 七层，让覆盖关系一目了然。
容器查询和媒体查询的区别？
媒体查询看视口，容器查询看最近的 container-type 祖先。 当组件需要在侧边栏和主区域呈现不同形态时，容器查询更合适。
popover 和 dialog 有什么区别？
<dialog> 需要 showModal() 才能进入模态； popover 可由 popovertarget 属性直接触发， 但默认是非模态浮层，点外部即可关闭。

关于本页

这一页没有使用一行 JavaScript。所有交互都由原生 HTML 属性和 CSS 伪类驱动：:target、:checked、 <details>、popover。

点击页面任意位置即可关闭此浮层。

原生 popover

使用 popovertarget 属性与目标 id 关联， 点击触发按钮即可打开或关闭，无需任何脚本。

它属于顶层（Top Layer）

popover 打开时会被提升到浏览器的顶层，不受父元素的 overflow 或 z-index 影响， 并通过 ::backdrop 提供半透明遮罩。
