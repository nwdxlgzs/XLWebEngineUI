纯 HTML + CSS 的网页示例

这个页面没有使用任何 JavaScript。 标签页、折叠面板、日间/夜间主题切换，全部由 HTML 结构和 CSS 选择器实现。

开始浏览

页面用了哪些技术

语义化标签

header、nav、section、article、footer 让页面结构清晰、利于阅读与检索。

CSS 变量

用 --var 定义颜色，切换主题只需改变量值，维护成本极低。

Grid 与 Flex

卡片网格用 Grid 自动换行，导航栏用 Flex 对齐，天然响应式。

原生控件

<details> 自带折叠交互，无需一行脚本。

纯 CSS 标签页

概览

点击上方标签即可切换内容，整个过程没有任何脚本参与。

  • 三个 <input type="radio"> 互斥选中
  • <label for> 负责点击代理
  • :checked ~ 兄弟选择器控制显示隐藏

结构示例

<div class="tabs">
  <input type="radio" name="tab" id="tab-1" checked>
  <input type="radio" name="tab" id="tab-2">

  <div class="tab-labels">
    <label for="tab-1">概览</label>
    <label for="tab-2">详情</label>
  </div>

  <div class="panels">
    <div class="panel">……</div>
    <div class="panel">……</div>
  </div>
</div>

实现原理

默认所有面板 display: none，当某个 radio 处于 :checked 状态时， 通过兄弟选择器把第 N 个面板设为 display: block：

#tab-1:checked ~ .panels > .panel:nth-child(1) {
  display: block;
}

常见问题

真的完全没有 JavaScript 吗？

是的。页面里没有任何 <script> 标签，也没有内联事件属性。

夜间模式是怎么实现的？

页面顶部的复选框被 label 点击后变为 :checked， 再用 #theme:checked ~ .page 覆盖一组 CSS 变量即可。

能自适应手机屏幕吗？

可以。布局基于 auto-fit 的 Grid 与可换行的 Flex， 并设置了 viewport 元标签。

这种方式的局限是什么？

无法处理复杂逻辑（数据请求、计算、状态持久化等）。 真正的应用场景仍需要 JavaScript 配合。
