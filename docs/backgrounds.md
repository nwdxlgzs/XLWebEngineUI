# 渐变与背景层

背景声明由私有 `cssbackground` 适配解析，与颜色、变量、嵌套样式和媒体规则共用重要性、层顺序、选择器权重及源顺序。`background` 展开并复位图片、位置、尺寸、重复、原点、裁剪、附着和颜色；`background-image` 等长属性只覆盖自己的部分。无效的普通声明忽略，变量替换后失效的声明按 unset 计算，inherit/revert/revert-layer 沿用现有层叠规则。作者 DOM、原始 CSS 和用户网页保持原文。

当前实现包括：

- linear、radial、conic-gradient 及其 repeating 形式；角度和方向、圆/椭圆、四类径向 extent、中心位置。
- 自动分布和显式色标、双位置硬边、负位置、超范围位置、过渡提示；长度、百分比和线性的 calc 运算。
- 已接入的现代颜色、currentColor、light-dark、显式插值空间及四种色相路径，alpha 预乘和缺失通道。旧式颜色默认 sRGB，现代颜色形式默认 Oklab。
- 多层背景的前后顺序、末层颜色、位置与边缘偏移、auto/长度/百分比尺寸及无固有尺寸渐变的 cover/contain；repeat/no-repeat/round/space 以及两轴组合。
- border/padding/content-box 原点和裁剪、圆角、scroll/fixed/local 附着、根/body 画布背景传播；块、Flex/Grid item、原子 inline 和普通 inline 分片共用绘制值。

颜色通道保持浮点到绘制适配器。实体颜色的 ARGB 输出继续使用其原有 gamut mapping；渐变在指定空间求插值后转换到目标 SDR sRGB，当前采用通道裁剪。非线性空间和提示曲线通过自适应色标近似，预乘通道差 0.0008 是细分判据，最多递归 12 层，不能当成全输入严格误差上界。硬色标保留重复位置，不把它平滑成连续过渡。

背景的重复坐标用内置 SkSL 程序计算，再调用 Skia 渐变 shader，不按 CSS 背景尺寸分配完整中间位图。测试包含 10,000,000×10,000,000 CSS 像素的背景尺寸。shader 在实际绘制时才创建，按背景绘制值缓存最多 64 项，色标及固定记录估算的预算为 4 MiB；这不是全部 Skia/GPU 分配的总预算。缓存属于文档帧/段落，销毁时释放；GPU 调用仍遵守既有同步执行器和 View 线程契约，没有新增资源文件、解压或后台任务。

位置、尺寸、颜色、裁剪和背景语义参与保留绘制比较；旧新损伤由同一绘制盒提供。滚动投影更新 local 偏移和画布定位参考，fixed 背景使用视口坐标。已有 AX 几何和语义保持共用布局，不通过关闭 AX 优化画面。普通 inline 目前按各可见分片计算背景，完整未断行 slice 坐标仍待完善。

## 验证与差异

语法测试验证几何、色标、层、简写、延迟长度及非法值。文档测试通过公开 SDK 检查实际像素、重要性/层回退、继承/变量失效、背景复位、圆角窄损伤、固定/局部附着、原子 inline、超大尺寸、静止跳过与同偏移完整重排对照；动态、静态库和真实内置 SwiftShader 分别执行。用户示例 2 的四个原始 `.grad` 块按原文消费，查询实际渐变声明，滚动后与强制重排逐字节对照。

2026-11-04 本机 Chrome 156.0.8078.80 的 30 组背景截图对照覆盖 330 个代表点。28 组代表点最大通道差不超过 1/255。另两组保留具体差异：25% 提示的指数曲线与浏览器粗分段近似最大差 11/255；旋转的 repeating conic 在两个恰落硬边的点因浮点边界选择相反色，差 255/255，其余代表点相同。证据为 `build/reports/backgrounds/browser-comparison.json`，初次失败和修正前结果另存，不以代表点对照宣称所有像素一致或完整网页视觉认证。

实现语法参考 W3C CSS Images 3/4、CSS Backgrounds and Borders 3 以及 CSS Color 4/5；绘制使用本项目锁定的 Skia `SkGradient` 和 `SkRuntimeEffect` API。未修改第三方源码，也未新增许可或运行依赖。具体双端检查和阶段包以 TODO 的最终记录为准。

## 仍需推进

URL 图片/完整 image-set/cross-fade/element/paint、background-clip:text、背景混合模式、渐变动画、全部 CSS 数学和其他尺寸/位置扩展仍待接入。多 stop 的完整色域映射、极端重复周期精度、提示与浏览器算法差异、硬边像素选择及完整 inline slice 继续完善。当前色标预算为每渐变最多 256 个逗号分隔项、采样最多 8192 项，每声明 64 KiB/8192 tokens/64 层括号，每背景最多 64 层；超出计算预算不代表标准上该输入无效。

本阶段不能替代完整 CSS、定位、动画、媒体、其他平台 AX、macOS/Web 或旧系统实际验收。纯滚动复用布局仍有效，动态 DOM 的细失效、AX 发布和 GPU 直接呈现继续按总计划推进。
