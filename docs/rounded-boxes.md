# 圆角与统一曲线裁剪

`border-radius` 和四角长属性进入现有样式层叠、变量、继承与层回退链。简写支持
1–4 个水平值和可选 `/` 后 1–4 个垂直值；长属性支持一对椭圆半径。支持百分比、
px/em/rem、绝对长度及已支持的视口单位，以及线性 `calc()` 的加减、标量乘除和括号。
负的直接值无效；计算值在最终使用时钳制到零。加减要求两侧空白，数学函数里的
无单位零保留 number 类型。`min()`/`max()`/`clamp()`、字体度量单位、完整现代数学函数
与转义单位尚待补齐。

半径存为私有长度/百分比表达式，到布局获得最终边框盒时解析，再统一缩小重叠半径。
背景、各边边框和 overflow 内缘使用同一 `RoundedRect`。背景保留原有矩形快路径；
圆角边框支持 solid/double/dotted/dashed/groove/ridge/inset/outset，保留各边颜色与宽度。
不同宽度的相邻边采用角部连接线划分颜色区域；点划线目前沿中线描边，未做所有
不等宽接角的浏览器级排布。半径伸入对侧边框的极端厚边框仍使用规范化内圆角，
尚未实现不足 90 度的截断椭圆内弧。

`Clip` 保持独立轴矩形范围，并共享不可变曲线交集；仅需要曲线的路径分配几何。
内容在两轴 overflow 均非 visible 时按 padding 内缘裁剪；单轴 clip、另一轴 visible
仍沿用独立轴规则。嵌套滚动、Flex/Grid、文字及原子行内内容沿既有 frame 的
move/merge/clip 链传递，绘制交给 Skia 的圆角裁剪。每个交集最多 256 条曲线，超过
上限返回 `XL_UNSUPPORTED`，不会静默丢掉裁剪。

指针和滚动命中检查真实曲线；文字命中复用同一个内容 clip。AX 继续提供矩形包围盒，
完全落在切除角内的节点保留语义并标记 OFFSCREEN。多个曲线求交的可见矩形是保守
包围范围，不是精确轮廓。`xl_view_node_bounds` 仍返回布局盒；AX 和文字/选区查询
返回各自按 clip 裁剪的矩形。先前发布的不可变 AX 更新不随新帧改变。

行内分片在对应起止边保留圆角，使用每片最终盒解析百分比，支持 RTL 边的对应。
完整 CSS slice 的虚拟未断行盒、大百分比和超大半径跨片拼接、box-decoration-break:clone
仍待实现，不把当前分片行为当作完整 slice 一致性。普通单盒 outline 沿圆角扩展；
多片继续使用既有轮廓联合算法。corner-shape、border-image、背景图片/渐变、变换、
阴影及尚未实现的替换内容媒体接口继续按总计划推进。

保留式场景比较包含半径和曲线 clip，旧新几何均进入损伤计算；静止帧继续跳过绘制。
CPU 曲线光栅化在窄裁剪区可能重新分段，改变抗锯齿覆盖率，因此脏区会扩展到与之
相交的完整曲线范围，并迭代包含随后相交的曲线。原子场景和段落携带实际曲线范围，
不只携带已经裁剪的墨迹；矩形路径保持原有局部更新。这会增加圆角区域内小更新的
重画面积，避免窄条更新与整帧出现不同边缘。后续可用缓存曲线覆盖率减少这部分代价。
这次实现不增加公开 ABI、运行依赖或线程，也不会因空盒/几何查询预先解压 ICU。
所有修改属于引擎源码，第三方锁源及补丁无需变更。

直接验证覆盖几何、语法/变量/层、背景与边框像素、内缘及嵌套 overflow、Flex/Grid、
滚动与点击、文字命中、AX 旧快照、行内/原子盒、outline，以及半径变化/移动后的
局部与整帧逐像素对照。动态与静态 SDK 使用同一测试；GPU 项必须实际使用内置
SwiftShader。原始用户网页只读消费。平台结果与阶段包证据记录在 TODO/WORKMEM；
这些检查不替代完整现代网页、旧系统或全部平台验收。

实现依据为 CSS Backgrounds and Borders Level 3 的 Corner Shaping、Corner Clipping、
Overlapping Curves，以及 CSS Values and Units Level 4 的数学类型与运算符语法。
