# CSS 嵌套

`src/style/nesting.cpp` 在作者文本与私有 Lexbor AST 之间编译嵌套规则。HTML、style
文本、内联 style 属性及挂载的 CSS 内容保持原文；展开仅用于私有样式匹配。

支持显式 `&`、隐式后代、`>`/`+`/`~` 相对关系、多层嵌套、选择器列表和同一选择器
中的多次 `&`。字符串、注释、转义、方括号及函数参数按 token 区分；自定义属性中的
花括号作为值保留。父列表按 `:is()` 的最大 specificity 处理，不做笛卡尔积展开；
`:where()` 仍为零权重。伪元素不能被 `&` 代表，但父列表中的伪元素仍贡献最大权重；
编译时使用永不匹配的分支保留这部分权重，不会注入 DOM 节点、class 或属性。
文档样式表最外层的 `&` 按文档根作用域、零权重处理。

连续声明在原位置生成独立规则，所以嵌套规则前后、条件组内外的声明维持源顺序。
直接声明继续匹配父规则的元素及伪元素，保留父列表逐分支权重；这与显式 `& {}`
的匹配和最大权重有区别。嵌套 `@media`、命名/匿名 `@layer` 接现有求值器和层叠，
首次变为活动的规则才展开简写。`@supports`、`@container`、`@scope` 和
`@starting-style` 的结构在编译输入中保留，但当前活动规则收集不执行它们，不把
识别其分组语法写作已经实现对应能力。未知嵌套 at-rule 跳过。

选择器仍受当前 Lexbor/引擎支持范围约束。无效普通选择器列表不通过放进宽容的
`:is()` 获得意外匹配；`&suffix` 不是 Sass 字符串拼接。完整命名空间、所有错误恢复、
完整伪元素、CSSOM 的 CSSNestedDeclarations/CSSStyleRule 接口和动态样式表编辑继续
推进。现有 `getComputedStyle(...).getPropertyValue()` 仍是声明序列化包装，不代表
完整浏览器计算样式、命名属性 getter 或 CSSStyleDeclaration。

三方修复在 `third_party/patches` 中：`lexbor-selector-retry.json` 让函数选择器与复合
选择器失败后继续尝试剩余祖先、兄弟或后代候选；`lexbor-focus-parser.json` 补齐各层
函数参数内的权重累加和每个分量的饱和。配方从锁定原始文件重新生成两个编译输入，
不会修改校验源码。许可仍沿用原 Lexbor Apache-2.0，补丁与配方进入依赖构建键。

编译缓存按 Document、样式来源元素和原文组织。媒体状态、class/checked/focus 或
普通属性变化复用不变的编译结果；文本/挂载变更产生新编译结果，旧结果在全部元素
和生成项清除层叠引用后释放。不同样式来源即使字节相同，也不共享可变声明 AST。
导航销毁对应文档缓存，Runtime 间没有全局样式缓存。

匹配为右侧复合选择器建立 tag/id/class 候选索引，最后仍由同一选择器求值器判断。
变量替换按实际自定义属性绑定环境合并，无本地定义的后代复用继承环境；每次使用
仍计入原有计算代次预算。编译样式表的已解析变量结果按原始声明和值缓存，防止
跨规则共享改变源顺序；达到 2048 项或 2 MiB 键文本阈值后，在下一次已清空层叠的
刷新中回收，其余结果使用当代存储。该阈值不是整个解析 arena 或 Document 的总内存。

当前上限：单样式输入 16 MiB、输出 32 MiB、每个选择器 64 KiB、1,048,576 tokens、
语法块栈 128、规则/分组递归 64、输出规则 65,536；每代保留的样式原文和编译文本
合计不超过 64 MiB。超限返回 XL_UNSUPPORTED，不静默裁掉后半份样式。匹配与缓存
仍归 UI 线程，没有新增线程或运行依赖，空页面/样式查询不触发 ICU 解压。

直接测试覆盖权重、源顺序、伪元素直接声明、关系回溯、条件/layer、动态状态、
linked/style 替换与重挂、缓存跨过 2048 项、像素/AX 旧快照、静止复用及原始用户网页。
CPU/静态库和实际 SwiftShader 使用同一行为测试。各平台结果和交付包记录在 TODO；
该阶段不替代完整现代网页、全部 CSS 嵌套边界或旧系统实机验收。

语义依据为 W3C CSS Nesting Module Level 1 的 Nesting Selector、Mixing Nesting Rules
and Declarations 与 Nested Declarations Rule。
