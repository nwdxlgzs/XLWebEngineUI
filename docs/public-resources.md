# Runtime 资源接口与 SDK 集成

本阶段将内部资源服务、压缩 ICU 数据和文字规范化接入公开 C ABI。网页、显示、AX 与媒体的最终 SDK 接入继续由 PLAN 跟踪；资源阶段不是完整引擎交付。

## 所有权与线程

`xl_runtime_create` 只创建轻量 Runtime。资源服务、压缩数据解码和工作线程都在实际请求或显式预热后才开始。`xl_runtime_resource_stats` 可验证未用资源的解压次数及工作线程数为零。

Runtime 操作属于创建它的 UI 线程。`xl_runtime_request_resource` 和 `xl_runtime_prewarm_resource` 立即创建异步请求，`xl_resource_request_poll` 在未完成时返回 `XL_BUSY`；调用者由自己的事件循环选择再次轮询时机。SDK 不接管宿主事件循环，不在 UI 上等待后台解压。

请求建立后可在任意线程轮询或取消。取消只影响这个请求；相同资源的其他请求继续使用合并的加载结果。释放尚未完成的请求会取消它自己的结果。每个 C 句柄由外部唯一所有者管理，释放不能与同一句柄的其他调用并发；C++ 包装采用不可复制、可移动的所有权。

成功轮询返回独立的只读资源租约。数据指针在该租约释放前有效，缓存整理、其他请求释放和 Runtime 销毁都不能使它失效。请求和租约可以晚于 Runtime 释放，但必须在卸载 SDK 库之前释放全部句柄。

`xl_runtime_set_allocator` 必须在首次资源请求或文字准备前调用。分配/释放回调成对提供、不得抛异常，用户上下文须活到 Runtime 及其全部请求和数据租约释放；分配器回调在资源服务和内存池锁外执行。回调用于宿主显式请求的解压数据块，SDK 自身的元数据仍由其运行库管理。

## 文字数据生命周期

`xl_runtime_prepare_text` 是固定文字流程的显式准备步骤：尚未加载 ICU 数据时返回 `XL_BUSY`，完成后注册内存数据并返回 `XL_OK`。`xl_runtime_normalize_utf8` 也会按需调用相同准备过程。两者均不把 `.dat` 解压到文件系统。

每个使用文字的 Runtime 持有私有 ICU 会话令牌。SDK 内部互斥保护首次注册、使用者计数和最终清理；多个 Runtime 可在不同 UI 线程使用各自接口。任一 Runtime 存活时，其他 Runtime 的销毁不会调用最终清理。最后一个会话退出后，先清理私有 ICU 再释放其数据租约；后续会话允许重新注册。

共享 ICU 数据始终由 SDK 分配器持有，避免首个 Runtime 的宿主分配器上下文被其他 Runtime 隐式延长寿命。默认分配器下可复用该 Runtime 已请求的数据；配置宿主分配器时，内部文字数据通过独立的 SDK 资源服务按需加载。已有 ICU 会话可直接复用，不启动第二个 Runtime 的资源线程。首次注册前同时准备的多个 Runtime 仍可能各自解压，最终只固定一份注册数据。

资源统计合计当前 Runtime 的显式资源服务和内部文字资源服务。`shared_text_data_bytes` 单独显示该 Runtime 关联的 SDK 共享 ICU 数据量；它可能与 `live_bytes` 重叠，也会出现在其他使用同一数据的 Runtime 中，不能直接累加为进程用量。内部文字服务的可回收缓存预算为零，由 ICU 会话租约固定数据，避免与显式资源服务相加后超出 Runtime 的缓存预算；活跃租约与共享固定数据另计。

未来字体/整形/布局使用 ICU 时，也必须持有同一令牌，且令牌必须比 ICU 对象更晚释放。单独复制 ICU 的全局状态或绕过令牌直接调用清理，会破坏该约束。

NFC 接口使用 UTF-8 输入，输出大小不含 NUL。缓冲不足返回 `XL_BUFFER_TOO_SMALL`，报告所需大小并保持输出不变；非法 UTF-8 返回 `XL_INVALID_ARGUMENT`。预热尚未完成时仍返回 `XL_BUSY`。

## 库与构建边界

构建期压缩器由锁定 Zstd 源码使用 Clang 编译，工具路径和生成目录都在 build 下。资源目录带输入/输出哈希；删除 build 后由资源清单、上游锁与配方重建。

动态 SDK 链入 ICU 与仅解压的 Zstd，并仅导出公开 C ABI。静态 SDK 合并所需私有归档，Zstd/Huffman/FSE 等全局 C 符号在合并后统一改名；ICU 使用项目后缀，公开头不暴露任何第三方类型。最终包只要求声明的系统链接项，不要求客户拥有开发机的第三方缓存。

本阶段须验证两平台 Debug/Release、移动安装树后 C 动态/C++ 静态消费、宿主同名私有库符号共存、跨 Runtime ICU 生命周期、活跃租约和卸载顺序。第三方许可和资源构建记录随包分发。验收结果以 TODO 和实际 CI 报告为准。
