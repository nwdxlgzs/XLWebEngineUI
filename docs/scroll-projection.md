# 保留布局的滚动投影

纯滚动现在复用最近成功的布局和段落。文档 revision、drawable 尺寸均未变化时，View 将保留的几何投影到新滚动位置，不再重新解析样式、排版文字或构建 AX 语义，`layout_frames` 保持不变。API、键盘、滚轮、焦点和编辑光标显现共用这一入口；DOM、样式、字体、挂载资源或尺寸变化仍走真实布局。

布局期间，私有 `FrameProjection` 为绘制项、文字、轮廓片段、节点盒、命中曲线、summary 标题和滚动区保存静态位置及滚动祖先。每层裁剪分别保存自己的滚动祖先，因此内层内容移动时，其滚动口保持原位；外层滚动时，内层滚动口也随之移动。正负偏移、分数像素、嵌套圆角裁剪与视口背景使用同一规则。

投影生成新的帧数据，段落和不可变投影元数据共享，AX 只更新可见边界和 OFFSCREEN。角色、名称、关系、状态、DOM 顺序及 UTF-16 映射沿用已有语义；已交付给宿主或 UIA 工作线程的 AX 批次保持不可变。几何查询仍在滚动待同步时返回 `XL_BUSY`，成功 render 后与画面一致。偏移属于 View，不会串到显示同一 Document 的其他 View。

原子 inline 内部的绘制场景按滚动偏移生成独立、不可变的覆盖表，绘制和外层文字复用原段落。带滚动绑定的场景不会仅凭当前像素相同而与另一次布局共享，避免导航后错误引用旧滚动节点；损伤范围保守包含整个可滚原子盒，保证滚入内容能刷新。投影、场景替换和 View 操作均归 Runtime UI 线程，没有新增后台任务或解压流程，也没有新增公共 ABI。

本阶段同时修复颜色专有计算暴露的 Lexbor 空级联问题：元素只有颜色声明时，其 inline list 可以存在而 Lexbor cascade 为空。受控补丁 `third_party/patches/lexbor-empty-inline-style.json` 允许此时替换和移除 style；从锁定原文生成独立 C 文件，补丁、配方与哈希进入依赖键，原始第三方源码保持只读。

## 验证与实测

`document.scroll_projection` 使用嵌套 overflow、圆角、分数及反向偏移、原子 inline、重复导航、多 View 和文字命中场景。每次纯滚动断言 revision 和布局次数不变；随后在相同偏移修改无视觉影响的 data 属性，触发完整重排，逐字节比较像素，并对照所有 AX 节点的几何和状态。动态库、静态库及真实内置 SwiftShader 分别执行，旧 AX 快照与 resize 重排另有断言。

2026-11-04 本机 Windows Debug、960×640、Raster、原 HTML 不改且不执行脚本，各页六次有效滚动。旧基线使用颜色阶段真实包内 DLL，新值来自最终实现 DLL `c06b77e4170f6e2a429210886e6dc650d7f29df5766fa3e7c8e7210e27360830`。旧值复用冻结记录，两组不是同期重测；耗时受本机负载影响。

| 用户网页 | 旧中位耗时 | 新中位耗时 | 新增布局次数 |
|---|---:|---:|---:|
| 纯 HTML 与 CSS 示例 1 | 140.94 ms | 16.68 ms | 0 |
| 纯 HTML 与 CSS 示例 2 | 1692.61 ms | 52.53 ms | 0 |
| 观察和现代 Web 特性的差异 | 259.18 ms | 4.78 ms | 0 |

三页最终 RGBA 均与旧库逐字节一致。完整原始证据在 `build/reports/scroll-projection/page-comparison.json` 和 `page-comparison-final.json`；前者记录早期实现的同期前后测量，后者明确记录最终 DLL 与复用的旧基线。

同一最终 DLL 的一个隐藏原生窗口测试启用 UIA，AUTO 实际使用 D3D12 和内置 DXC；示例 2 的六次 WM_MOUSEWHEEL 输入确实滚动到 y=288，布局和 revision 增量均为 0，中位 96.06 ms。它验证真实 HWND 事件队列到 render 的通路，不代表物理输入到屏幕的时延认证。

## 继续推进的边界

本阶段没有实现独立滚动条带合成、GPU 直接呈现或完整异步滚动。滚动仍可能重绘整个视口、复制帧容器并发布 AX 快照；复杂页尚未达到 60 Hz 的帧预算。定时脚本引发的小 DOM 修改仍可能全布局，首帧与文字、计算样式及 AX 增量继续优化。测试不通过关闭无障碍、修改用户 HTML 或延长超时来获得性能结果。

本阶段证据仅覆盖本机 Windows 11 和 WSL musl Debug 的直接检查。Win7、旧 Linux、macOS 和 Web 的实际兼容验收、完整现代 CSS、定位、渐变、媒体及完整引擎仍按总计划继续。
